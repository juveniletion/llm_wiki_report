# ---- 文档解析（**「上传新资料并编译」必需**）----
#
# ⚠️ 这一组曾经只写在注释里（"要跑摄入的话另装"），是判断失误：
#    「上传资料 → 编译进知识库」是本系统的**核心能力之一**（赛题 5.1.2
#    要求知识库支持 PDF/Word/TXT），不是可选项。
#
#    而缺了它的失败方式**极其隐蔽**：`ingest_raw.parse_to_text()` 把
#    ImportError 捕获后返回字符串 `【解析失败: 缺少依赖 fitz】`——
#    这个字符串会被**当成文档正文存进知识库**。于是：
#      · 文件在库里有记录、有哈希、看起来摄入成功了
#      · 但检索不到任何内容（正文是一句错误提示）
#      · 而且不报错、不告警，只有真去查那份文件才发现
#    ⇒ 沉默的降级比报错坏得多。装齐，别让它有机会降级。
#
# ⚠️ PDF 用的是 **PyMuPDF（`import fitz`）**，不是 pypdf——
#    这里原先写的是 "pip install pypdf"，但代码从不 import pypdf，
#    照做会装一个用不上的包、而真正要的 fitz 仍然缺。
pymupdf>=1.24      # PDF（代码里 import fitz）
openpyxl>=3.1      # .xlsx
xlrd>=2.0          # .xls（老格式，openpyxl 不支持）
# （.docx 用上面的 python-docx）

# ---- Word 文档（导出侧必需，**不是可选**）----
#
# ⚠️ 这条曾经只写在注释里（"要跑摄入的话另装"），是判断失误：
#    `export_doc.to_docx()` 与 `template_docx.fill_docx()` 都直接 `import docx`，

#    ⇒ 它是部署必需项，放在正式依赖里。
python-docx>=1.1
